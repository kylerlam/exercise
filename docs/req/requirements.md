# Exercise v0.1.0

来源：2026-11-16 用户要求、共用每月训练记录表及其截图。交付可运行应用，并完成开发和测试。

- 参考 Daily Todo 和 Habit（本地最匹配项目为 CirGrid）的代码架构、登录系统和 UI。原项目仅作只读参考。
- 项目独立使用 Python 标准库 HTTP 服务、SQLite、原生 JavaScript/CSS；不共享原应用账号、会话或业务数据。
- 每天可记录多个力量训练动作，横向字段顺序固定为：部位、动作、组数、次数。组数和次数必须为正整数，浏览器与 API 都校验，数据库保持整数。
- 有氧单独录入运动、分钟数、可选公里数及备注；时长和距离允许小数。
- 支持新增、编辑和删除记录，选定日期补记。保存失败保留输入，并发编辑冲突不得静默覆盖。
- 日历按月浏览，点击日期查看当日记录。可切换年月、回到今天。
- 月统计显示当月所有真实日期，以“日期 / 训练记录”连续向下滚动，不分成 PDF 的两部分。空白日保留；力量简写为“腿：深蹲×4×15”；有氧保留分钟和距离。
- 默认简体中文，沿用原应用主题和设置风格。账号支持改名、修改密码及退出登录。
- 验收覆盖登录、前后端数据类型、增删改、日期边界、月统计、日历、持久化、会话隔离、桌面和手机交互。
- 本次先交付本机可运行服务；未要求建立外部仓库、公开站点或改动已有 NAS 应用。
